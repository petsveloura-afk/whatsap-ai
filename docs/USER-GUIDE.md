# מדריך שימוש - Smart Sniper AI

המדריך הזה זהה לזה שבלשונית **החשבון** באפליקציה.

## התחלה מהירה
1. **הגדר מה מחפשים** - באשף החיפוש כתוב בשפה חופשית, למשל: דירת 3 חדרים בחולון עד 5,500. אפשר לתקן לפני שמירה.
2. **הבא מודעות** - הדבק מודעה או כמה מודעות יחד, חבר מקור RSS/JSON ציבורי, או הפעל גילוי מהרשת (דורש מפתח של מנוע חיפוש).
3. **סקור ודרג** - כל הזדמנות מקבלת ציון 0 עד 100, הסבר וסימני אזהרה. שמור או דחה כדי שהמערכת תלמד מה מתאים לך.
4. **צור קשר** - התקשר, וואטסאפ עם הודעה מוכנה, מייל או קישור למודעה. המערכת לא שולחת הודעות בשמך.
5. **דבר עם הסוכן** - מנתח, יוצר חיפושים, מסמן מודעות וזוכר העדפות. אין לו כלי מחיקה.
6. **כלים מתקדמים** - בדיקת הונאות, מחיר הוגן, מו״מ, מחשבונים, מעקב לקוחות ודוחות.

## הפרופיל והחיבורים (לשונית החשבון)
- **שלמות הפרופיל** - ציון עם צעדים הבאים.
- **מה המערכת למדה עליך** - נלמד רק ממה שבחרת בפועל, ורק כששתי מודעות לפחות מסכימות. "סנכרן לזיכרון" שומר זאת בזיכרון הסוכן (לא יוצר כפילויות).
- **וואטסאפ** - התראות אחרי הסכמה מפורשת; אפשר לבטל בכל רגע. שליחה בפועל דורשת WhatsApp Cloud API בשרת.
- **טלגרם** - מקור מודעות: יוצרים קוד חיבור לחיפוש, שולחים אותו בצ׳אט עם הבוט, וכל הודעה בצ׳אט תנותח.
- **תצוגה ונגישות** - גודל טקסט, ניגודיות גבוהה, אנימציות מופחתות (נשמר במכשיר).

## שאלות נפוצות
- **מה אומר הציון?** התאמה 0-100 לפי החיפוש שהגדרת. התאמה אישית יכולה להזיז עד 10 נקודות, וההסבר מופיע בפירוט.
- **מה הם סימני אזהרה?** אינדיקטורים בלבד, לא הוכחה. לפני תשלום יש לוודא מול המוכר.
- **למה אין תוצאות?** המערכת לא גולשת באתרי מודעות. נתונים נכנסים מהדבקה, RSS/JSON ציבורי או מנוע חיפוש רשמי עם מפתח.
- **איך מוחקים זיכרון?** מחיקת פריט בודד, כיבוי התאמה אישית, או ייצוא ומחיקת החשבון.
- **איך מפעילים את המוח החכם?** מוסיפים מפתח חינמי בשרת ומדליקים את הדגל `llm_extraction` (ניהול). בלי זה הסוכן עובד בכללים מקומיים.
- **התקנה כאפליקציה** - Android/Chrome: תפריט ← התקן אפליקציה. iPhone: שיתוף ← הוסף למסך הבית.

## קיצורי מקלדת
`Alt+Shift+1..9` מעבר ללשונית, `Enter` שליחה לסוכן, `Shift+Enter` שורה חדשה, `Tab` ניווט (הקישור הראשון מדלג לתוכן).
